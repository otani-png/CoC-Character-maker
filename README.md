# キャラシメーカー（深淵の書）

クトゥルフ神話TRPG（6版）のキャラクターシートを、ボタン1つで生成するWebツール。
UIは姉妹ツール [成長判定ツール（研鑽の書）](https://github.com/otani-png/ccfolia-growth-tool) と同じ土台で、白基調のシンプルなデザイン（ライト／ダーク自動切替）。

**→ 公開ページ: https://otani-png.github.io/CoC-Character-maker/**

## できること

- **ワンクリック生成** — 名前・性別・年齢・職業・能力値・技能値を一瞬でロール
- **時代の切替** — 現代／1920年代（大正〜昭和）。時代で名前の傾向が変わり、1920年代ではコンピューター・電子工学など当時なかった技能を除外
- **詳細設定（推奨技能・技能上限）** — 「詳細設定」を開くと細かい設定が出る
  - **推奨技能** — シナリオが推奨する技能をチェックすると、目標値（既定60）まで必ず確保する。シートには「推奨」タグが付く
  - **技能値の上限** — KP が作成時の技能上限を決めている場合に設定（既定90。信用・回避・母国語は対象外）
- **職業に合った技能振り** — 17職業それぞれの職業技能に、職業ポイントを重み付けで自動配分。趣味ポイント（INT×10）も別途配分
- **背景設定の自動生成** — 出身・生い立ち・職業に至った経緯・現在の不穏な兆しを組み合わせた、クラシックな雰囲気のバックストーリー
- **ココフォリア駒データ出力** — コピーして、ココフォリアのルームに Ctrl+V で貼るだけで駒になる
  - HP / MP / SAN（ステータスバー連動）
  - 全技能の `CCB<=` 判定コマンド
  - 武器ダメージロール（DB込み。例 `1d3+1d4 【ダメージ：こぶし】`）
  - 能力値×5ロール、正気度ロール
- **テキスト出力** — キャラシ全文をプレーンテキストでコピー

## 準拠ルール（6版）

| 項目 | 計算 |
|---|---|
| STR / CON / POW / DEX / APP | 3D6 |
| SIZ / INT | 2D6+6 |
| EDU | 3D6+3（上限18） |
| HP | (CON+SIZ)÷2 切り捨て |
| MP | POW |
| SAN / 幸運 | POW×5 |
| アイデア / 知識 | INT×5 / EDU×5 |
| 回避 | DEX×2 |
| 母国語 | EDU×5 |
| 最低年齢 | EDU+6（年齢指定時はEDU側を調整） |
| 技能上限（作成時） | 既定90（画面で変更可） |

> **職業技能ポイントについて**：6版の公式ルールでは全職業とも `EDU×20`（職業ごとに違うのは "使える技能リスト" の方）。本ツールは体力系の職業（警察官・軍人・冒険家・船員など）を `EDU×10 + STR/DEX×10`、社交系（ディレッタント）を `EDU×10 + APP×10` にするなど、職業ごとに配分点を変えている。純粋な6版に戻すなら `index.html` の `OCC` の `pts` をすべて `s=>s.EDU*20` にすればよい。

## 開発

`index.html` 1ファイル構成（ビルド不要・依存なし）。

```bash
# ロジックのテスト（Node.js があれば動く。npm install 不要）
node test/logic.test.mjs
```

テスト内容：能力値の範囲、派生値の計算式、年齢とEDUの整合、技能上限（cap）、時代による技能の除外、職業ポイント、ダメージボーナス境界値、ココフォリアJSONの構造、全職業の生成・背景文生成。
