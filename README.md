# ぱっきゃら（ぱっときゃら工房）

ワンクリックでCoCの探索者を1人ぶん作るツール。旧称：キャラシメーカー（深淵の書）。


クトゥルフ神話TRPG（6版）のキャラクターシートを、ボタン1つで生成するWebツール。
UIは姉妹ツール [成長判定ツール（研鑽の書）](https://github.com/otani-png/ccfolia-growth-tool) と同じ土台で、白基調のシンプルなデザイン。

**→ 公開ページ: https://otani-png.github.io/CoC-Character-maker/**

## できること

> 時代（1920年代）と7版モードは中に残してあるが、2026-10-18から画面には出していない（7版は簡易版のため）。

- **ワンクリック生成** — 名前・性別・年齢・職業・能力値・技能値を一瞬でロール
- **年齢層** — ランダム／子供（10〜14）／学生（15〜22）／社会人（22〜60）／シニア（60〜80）。年齢を直接入れればそちらを優先。子供・学生の職業は「学生」になる
- **詳細設定（推奨技能・技能上限）** — 「詳細設定」を開くと細かい設定が出る
  - **推奨技能** — シナリオが推奨する技能をチェックすると、目標値（既定60）まで必ず確保する。シートには「推奨」タグが付く
  - **技能値の上限** — KP が作成時の技能上限を決めている場合に設定（既定90。信用は対象外）
  - **方向性** — アタッカー／探索役／交渉役／知識役／回復役。合う職業が出やすくなり、その技能に多めにポイントが入る
  - **表示する欄** — 能力値・職業技能・背景設定・全技能のうち、要らない欄を外せる（テキスト出力からも消える）
- **職業に合った技能振り** — 18職業（学生を含む）それぞれの職業技能に、職業ポイントを重み付けで自動配分。趣味ポイント（INT×10）も別途配分
- **背景設定の自動生成** — 出身・生い立ち・職業に至った経緯などの文の部品を組み合わせて作る（AIで書いているのではない）。出身は「都会の真ん中」「山あいの村」など、具体的な地名を使わない言い方
- **ココフォリア駒データ出力** — コピーして、ココフォリアのルームに Ctrl+V で貼るだけで駒になる
  - HP / MP / SAN（ステータスバー連動）
  - 全技能の `CCB<=` 判定コマンド
  - 武器ダメージロール（DB込み。例 `1d3+1d4 【ダメージ：こぶし】`）
  - 能力値×5ロール、正気度ロール
- **テキスト出力** — キャラシ全文をプレーンテキストでコピー

## 準拠ルール（6版）

| 項目 | 計算 |
|---|---|
| STR / CON / POW / DEX / APP | 3D6 |
| SIZ / INT | 2D6+6 |
| EDU | 3D6+3（上限18） |
| HP | (CON+SIZ)÷2 切り捨て |
| MP | POW |
| SAN / 幸運 | POW×5 |
| アイデア / 知識 | INT×5 / EDU×5 |
| 回避 | DEX×2 |
| 母国語 | EDU×5 |
| 最低年齢 | EDU+6（年齢指定時はEDU側を調整） |
| 技能上限（作成時） | 既定90（画面で変更可） |

> **職業技能ポイントについて**：6版の公式ルールでは全職業とも `EDU×20`（職業ごとに違うのは "使える技能リスト" の方）。本ツールは体力系の職業（警察官・軍人・冒険家・船員など）を `EDU×10 + STR/DEX×10`、社交系（ディレッタント）を `EDU×10 + APP×10` にするなど、職業ごとに配分点を変えている。純粋な6版に戻すなら `index.html` の `OCC` の `pts` をすべて `s=>s.EDU*20` にすればよい。

## 開発

`index.html` 1ファイル構成（ビルド不要・依存なし）。

```bash
# ロジックのテスト（Node.js があれば動く。npm install 不要）
node test/logic.test.mjs
```

テスト内容：能力値の範囲、派生値の計算式、年齢とEDUの整合、技能上限（cap）、年齢層、方向性、表示する欄、職業ポイント、ダメージボーナス境界値、ココフォリアJSONの構造、全職業の生成・背景文生成。

## バージョン

画面のいちばん下に `vX.Y.Z（日付）` と出る。数字は `index.html` の `VERSION` と `VERSION_DATE` で変える。

- 小さな直し（文言・見た目の調整）→ 下の桁を上げる（2.0.0 → 2.0.1）
- 機能を足した → 真ん中を上げる（2.0.1 → 2.1.0）
- 大きく作り替えた → 上の桁を上げる（2.1.0 → 3.0.0）

| 版 | 日付 | 何をしたか |
|---|---|---|
| 2.2.1 | 2026-10-18 | SNSで共有したときの画像（og.png）を追加。生まれと育ちで場所が食い違う文を直す |
| 2.2.0 | 2026-10-18 | 右側に作者（大谷書工房・note・X）の表記を追加。狭い画面ではページの下に出る |
| 2.1.3 | 2026-10-18 | 「版」の選択欄を画面から外す（6版固定） |

| 2.1.1 | 2026-10-18 | 使い方の説明を、入力欄の下からキャラクターシートの下へ移動 |
